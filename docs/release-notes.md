## 0.3.0

- 原始诊断中文显示支持 Windows、macOS、Linux 的 x64 / ARM64，以及 Alpine Linux 的 x64 / ARM64。请下载与 VS Code 扩展运行环境匹配的 VSIX；远程 SSH、WSL 和容器使用远端系统的包。
- 保留具体类型、变量名、修改建议、相关位置与完整原文；不会合并不同错误，也不会改动补全、普通文档和代码操作。
- 项目独立保存与恢复代理设置，保留自定义服务器和启用后自行修改的配置；更新后自动检查连接。
- 优化行尾提示、悬停解释、问题面板和“Rust 中文”菜单，统一 TypeScript / Rust 翻译规则。
- 验证 518 个 Rust 错误码及官方 rust-analyzer 0.3.3033、0.3.3041 的兼容性。
- 构建产物集中到 out/，原生二进制不再随 Git 源码提交。发布必须通过全部八个平台的构建、回归测试和包内容校验，并附 SHA256SUMS。

Linux GNU 包使用 Ubuntu 22.04 构建；Alpine 包使用静态 musl 代理。此次不提供 32 位 ARM、32 位 Windows 或浏览器 Web 扩展。macOS / Linux 图形界面的完整人工测试仍欢迎反馈。

从 0.1.x 升级：若提示旧版代理配置，请先使用“恢复原始诊断”核对旧备份，再重新启用中文显示。
